# Demo Video Guide

This file acts as a placeholder for the required demo video requirement.

Suggested 5-minute demo flow:

1. Login as admin or sales user
2. Create a customer enquiry
3. Create a quotation
4. Accept the quotation
5. Convert to sales order
6. Confirm the sales order
7. Reserve inventory
8. Dispatch the order
9. Show final stock changes

Use a screen recording tool and upload the final video to a cloud storage provider or attach it to the repository release notes before submission.
