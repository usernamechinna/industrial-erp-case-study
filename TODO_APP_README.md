# Local-storage To-do List

A responsive, dependency-free to-do application. Tasks are saved in the browser using `localStorage`, so they remain available after refreshes and browser restarts.

## Run

Open `todo.html` directly, or serve the repository with:

```bash
npx serve .
```

## Features

- Add tasks with the form or Enter key
- Mark tasks complete and delete tasks
- Filter all, active, or completed tasks
- Clear completed tasks
- Completion percentage indicator
- Accessible controls and responsive layout

Storage key: `focus-list.tasks.v1`.
